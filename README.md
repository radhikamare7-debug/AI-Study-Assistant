# AI Study Assistant

## Project Description
AI Study Assistant is an AI-powered web application designed to help engineering students understand topics, generate study materials, and manage their learning activities.

## Features
1. Student Registration
2. Student Login
3. Student Dashboard
4. AI Topic Explanation
5. Study Notes Generator
6. Question Paper Generator
7. Quiz Generator
8. Flashcard Generator
9. Text Summarizer
10. AI Study Assistant Chat
11. Prompt History
12. MySQL Database Integration

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- MySQL
- Google Gemini API

## Installation
1. Install packages using: pip install -r requirements.txt
2. Create a .env file with your API key and database settings.
3. Start MySQL Server.
4. Run: python web_app.py
5. Open http://127.0.0.1:5000

## Note
Gemini API responses depend on API availability and usage quota. Demo responses may appear when the API is unavailable.
